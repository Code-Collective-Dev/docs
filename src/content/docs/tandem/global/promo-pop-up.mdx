The promo pop-up shows an offer with an optional discount code and copy button. It can collect an email first and reveal the code after sign-up. It opens after a delay or when the pointer heads for the browser bar, then stays closed for the number of days you choose.

## Add the section

<Steps>

1. Open **Online Store > Themes > Customize** and go to any page.
2. Click **Add section** and choose **Promo pop-up**.
3. Fill in the content, then click **Save**.

</Steps>

## Reveal a code after sign-up

Create the discount in **Discounts**, enter its code in **Discount code**, then turn on **Show email sign-up**. Sign-ups are saved as customers with marketing consent, plus the tag you enter in **Customer tag**, so you can segment them later.

## Tips

- In the theme editor the pop-up only opens while the section is selected.
- Use **Hide for signed-in customers** so returning customers aren't asked again.
