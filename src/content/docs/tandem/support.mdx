Check the [FAQ](/tandem/faq/) and search these docs first; most questions are answered here. If you're still stuck, send us a message.

<LinkCard title="Contact support" description="Send us your question with your store URL and a screenshot." href="https://codecollective.io/themes/tandem/support" />

## Include in your message

- Your store URL, such as `your-store.myshopify.com`
- Which theme copy you're working on, if you have more than one
- What you expected to happen and what happened instead
- A screenshot or short screen recording

We reply within one business day, Monday to Friday.

## What support covers

| Covered | Not covered |
| --- | --- |
| Setting up and using theme settings, sections and blocks | Changes to the theme code |
| Bugs in the theme | Third-party apps and their widgets |
| Questions about how a feature works | Store setup outside the theme, such as shipping, taxes and payments |
| Help choosing the right section for a layout | Design or custom development work |
