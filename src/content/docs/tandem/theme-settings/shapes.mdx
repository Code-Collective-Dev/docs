Open **Online Store > Themes > Customize**, then click the paint brush icon for **Theme settings** and choose **Shapes**.

Shapes set the feel of the store: soft and rounded, or bold and graphic. Buttons become pills at a corner radius of 24 px and up.

## Settings

| Setting | Type | What it does |
| --- | --- | --- |
| Button style | Choice | Solid / Outline / Solid with hard shadow. |
| Button text case | Choice | As typed / Uppercase. |
| Button corner radius | Slider | 0 to 40px. |
| Input corner radius | Slider | 0 to 20px. |
| Card and image corner radius | Slider | 0 to 32px. Buttons become pills at 24px and up. |
| Line thickness | Slider | 1 to 3px. Borders on buttons, fields and bordered cards. |
| Product image style | Choice | Tile / Border / Border with hard shadow. Tile fills product images with the surface color. Border and hard shadow suit bold, graphic styles. |
