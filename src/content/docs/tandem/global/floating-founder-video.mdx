The floating founder video slides a small muted clip in at the edge of the screen. Shoppers can drag it to either side, and tapping it opens a player with sound and up to two buttons. Closing it hides it for the rest of the visit.

## Add the section

<Steps>

1. Open **Online Store > Themes > Customize** and go to any page.
2. Click **Add section** and choose **Floating founder video**.
3. Fill in the content, then click **Save**.

</Steps>

## Section settings

| Setting | Type | What it does |
| --- | --- | --- |
| Video | Video | A short portrait clip works best, under a minute. It plays muted in the small player and with sound once opened. |
| Label | Text |  |
| Starting side | Choice | Left / Right. Shoppers can drag the video to either side; it stays where they leave it. |
| Show after | Slider | 0 to 20 s. |
| Show on | Choice | All pages / Home page only. |
| **Open player** | | |
| Heading | Text | Leave empty to hide it. |
| Button label | Text | Leave empty to hide the button. |
| Button link | Link | A page, product, collection or web address. |
| Second button label | Text | Leave empty to hide the second button. |
| Second button link | Link | A page, product, collection or web address. |
| Button color scheme | Color scheme | Used for the first button in the open player. |
