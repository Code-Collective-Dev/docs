Custom Liquid adds your own Liquid or HTML, such as an embed from another service.

## Add the section

<Steps>

1. Open **Online Store > Themes > Customize** and go to any page.
2. Click **Add section** and choose **Custom Liquid**.
3. Fill in the content, then click **Save**.

</Steps>

## Section settings

| Setting | Type | What it does |
| --- | --- | --- |
| Liquid code | Liquid | Add app snippets or other code to create advanced customizations. |
| Color scheme | Color scheme | One of the schemes from Theme settings > Colors. |
| **Padding** | | |
| Top padding | Slider | 0 to 120px. |
| Bottom padding | Slider | 0 to 120px. |

## Tips

- Code here isn't covered by theme support. Test it on a copy of your theme first.
