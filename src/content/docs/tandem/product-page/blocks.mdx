Add blocks to the **Product information** section to build the column next to the gallery. Drag them to change the order. Blocks with nothing to show for a product, such as a rating on a product with no reviews, hide themselves.

## Blocks

### App

Adds a block from an installed app, such as reviews or subscriptions. Only apps that offer app blocks show up here.

### Size chart

| Setting | Type | What it does |
| --- | --- | --- |
| Link label | Text |  |
| Heading | Text | Uses the link label if empty. |
| Text | Rich text | Notes around the chart, such as how to measure. Connect a product metafield so each product can have its own. Tables go in the HTML field or a page. |
| Chart table (HTML) | HTML | Paste a table here, for example one copied from a spreadsheet converter. |
| Chart page | Page | Shows a page's content. Pages can hold tables, which suits one chart shared by many products. |
| Only show for options | Text | Option names separated by commas, like Size, Taille. Leave empty to show on every product. |
