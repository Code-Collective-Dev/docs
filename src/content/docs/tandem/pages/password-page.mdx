The password page shows your logo, your message, an optional newsletter sign-up and the password form. Set the message and password in **Online Store > Preferences**.

## Section settings

| Setting | Type | What it does |
| --- | --- | --- |
| Logo width | Slider | 60 to 300px. |
| Show newsletter sign-up | On or off |  |
| Color scheme | Color scheme | One of the schemes from Theme settings > Colors. |
