Open **Online Store > Themes > Customize**, then click the paint brush icon for **Theme settings** and choose **Typography**.

Choose any font from the Shopify font library for headings and body text. Fonts load from Shopify's servers and are included free.

## Settings

| Setting | Type | What it does |
| --- | --- | --- |
| **Headings** | | |
| Font | Font |  |
| Heading letter spacing | Choice | Tight / Medium / Relaxed. Tight suits bold sans-serif fonts. Relaxed suits serifs. |
| Heading case | Choice | As typed / Uppercase. |
| Heading size | Slider | 80 to 150%. |
| **Body text** | | |
| Font | Font |  |
| Body text size | Slider | 14 to 20px. |
