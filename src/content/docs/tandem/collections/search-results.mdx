The search results page has a search field, filters and sorting for products, and a grid that mixes products with matching articles and pages. Predictive search, which opens from the header, is set up in [Theme settings > Search](/tandem/theme-settings/search/).

## Section settings

| Setting | Type | What it does |
| --- | --- | --- |
| Color scheme | Color scheme | One of the schemes from Theme settings > Colors. |
| Results per page | Slider | 8 to 48. |
| Products per row on desktop | Slider | 2 to 5. |
| Show second image on hover | On or off | Shows the product's second image when a shopper hovers over the card. |
| Show vendor | On or off | Shows the brand above the product title. |
| Enable filtering | On or off | Filters apply to products. Set them up in the Search & Discovery app. |
| Enable sorting | On or off |  |
