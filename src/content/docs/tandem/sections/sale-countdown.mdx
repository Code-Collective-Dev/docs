The sale countdown counts down to a date and time in your store's time zone. The Bar layout is a slim strip for the header group; the Banner layout is a centered block for any page. When the sale ends it disappears or shows a closing message.

![The Sale countdown section](../../../../assets/shots/countdown-banner.jpg)

## Add the section

<Steps>

1. Open **Online Store > Themes > Customize** and go to the header group or any page.
2. Click **Add section** and choose **Sale countdown**.
3. Fill in the content, then click **Save**.

</Steps>

## Section settings

| Setting | Type | What it does |
| --- | --- | --- |
| End date and time | Text | In your store's time zone, written like 2026-12-01 09:00. |
| Layout | Choice | Banner / Bar. Bar is a slim strip for the header area, above or below the header. |
| Clock style | Choice | Boxes / Inline. |
| Small heading | Text | A short line above the heading, such as a category or a promise. |
| Heading | Text | Leave empty to hide it. |
| Text | Rich text | Shows in the Banner layout. |
| Countdown label | Text |  |
| Button label | Text | Leave empty to hide the button. |
| Button link | Link | A page, product, collection or web address. |
| When it ends | Choice | Hide / Show a message. |
| Message after the end | Text |  |
| Color scheme | Color scheme | One of the schemes from Theme settings > Colors. |
