Shopify resizes images for each screen, so upload them large and let the theme do the rest. These sizes give sharp results without making files too heavy.

| Where | Recommended size | Shape |
| --- | --- | --- |
| Hero, full width | 2800 x 1600 px | Landscape |
| Hero, phone image | 1200 x 1800 px | Portrait |
| Slideshow | 2800 x 1400 px | Landscape |
| Image with text | 1600 x 1600 px | Square or portrait |
| Collection tiles | 1200 x 1500 px | Portrait |
| Product images | 2000 x 2000 px | Square, or keep one shape for all products |
| Scroll story product shot | About 1400 px tall | Cut-out with a transparent background |
| Logos in a trust strip or logo list | 600 px wide | Single-line wordmark, no extra space |
| Blog featured image | 1600 x 1000 px | Landscape |

Use JPG for photos and PNG or SVG for logos. Keep the first image on the page under about 500 KB, because it loads before anything else.
