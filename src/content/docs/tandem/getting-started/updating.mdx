## Update Tandem

When a new version is available, Shopify shows an update notice next to Tandem in **Online Store > Themes**.

<Steps>

1. Click **Update** (or **View update**) next to Tandem.
2. Shopify adds the new version as a copy in your theme library, with your theme settings and content kept.
3. Preview the copy, then publish it when you're happy.

</Steps>

<Aside type="caution">
Changes you made to the theme code aren't carried over to the update. Keep a note of them so you can make them again.
</Aside>

See the [changelog](/tandem/changelog/) for what changed in each version.

## Licenses

A Tandem purchase covers one store. To use Tandem on another store, buy it again from that store. You can keep as many copies of Tandem as you like in one store's theme library, and duplicating it to try changes doesn't need another license.

If you're building a store for a client, buy Tandem from the client's store, or transfer the store to them with the theme included. See Shopify's help on [theme licenses](https://help.shopify.com/manual/online-store/themes/managing-themes/theme-licenses).
