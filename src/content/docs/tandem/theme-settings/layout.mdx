Open **Online Store > Themes > Customize**, then click the paint brush icon for **Theme settings** and choose **Layout**.

These settings control the width of the content and the space around it across every page.

## Settings

| Setting | Type | What it does |
| --- | --- | --- |
| Page width | Choice | Narrow / Normal / Wide. |
| Page margin | Slider | 12 to 64px. |
| Space between sections | Choice | Compact / Normal / Spacious. |
