# Code Collective docs

Source for [docs.codecollective.io](https://docs.codecollective.io), the help centers for Code Collective themes and apps. Tandem lives under `/tandem/`.

```sh
npm ci
npm run dev
```

Pushes to `main` are built and published to GitHub Pages.
