Open **Online Store > Themes > Customize**, then click the paint brush icon for **Theme settings** and choose **Colors**.

Tandem uses color schemes. Each scheme is a set of colors for one kind of background: a light page, a dark band, a highlight. Sections pick a scheme with their **Color scheme** setting, so changing a scheme updates every section that uses it.

Each scheme sets:

| Color | Where it's used |
| --- | --- |
| Background | The section background |
| Background gradient | Optional. Replaces the background with a gradient |
| Text | Headings and body text |
| Muted text | Secondary text, such as captions and compare-at prices |
| Accent | Sale prices, badges and highlights |
| Border | Lines, dividers and field borders |
| Surface | Cards and product image tiles |
| Button | Solid button background |
| Button label | Text on solid buttons |
| Secondary button label | Text on outline buttons |

## Edit a scheme

Open **Theme settings > Colors**, click a scheme and change its colors. Add a new scheme with **Add scheme**. Keep enough contrast between text and background: the editor warns you when contrast is low.

## Tips

- Give the cards in a section a different **Card color scheme** from the section so they stand out.
- In the scroll story, give the stage a different scheme from the section so **Expand while pinned** shows.
